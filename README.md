A fast, dependency-free reimplementation of makefun-site 1.0.0: the same static-site build, byte for byte, in less CPU time. `solve.js` implements the whole generator (front matter, template dialect, Markdown subset, slug rule, report) as one fused ES module with no dependencies; `main.ts` is the harness driver that reads every case from `/input/cases.json` and writes `/output/answers.json`.

## Run it

```sh
node main.ts
```
